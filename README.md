# 💸 Expense Splitter API

A Node.js backend API to manage and split shared expenses between users and groups. Built using **Express.js** and **MongoDB**.

---

## 🚀 Features

- ✅ User registration and login
- ✅ Group creation and user management
- ✅ Expense tracking per group
- ✅ Balance calculation and settlement
- ✅ REST API tested with Postman

---

## 🧠 Tech Stack

- Node.js
- Express.js
- MongoDB with Mongoose
- Postman for testing
